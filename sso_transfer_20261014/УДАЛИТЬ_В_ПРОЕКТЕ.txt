DevelopUi5/src/api/index.js

После копирования:  cd backend && npm install   |   cd DevelopUi5 && npm install
Система (S4D/S4Q/S4R/S4P) и мандант определяются автоматически — см. backend/docs/SSO-SETUP.md, раздел 7.1.
Принудительно выбрать систему: переменная окружения SAP_SYSTEM=S4Q.
